# GitHub & LinkedIn descriptions

## Repository name

`satellite-landuse-deep-learning`

## Recommended project title

**Satellite Land-Use Classification & Deep Learning — CNNs, EfficientNetB0 and PyTorch**

## GitHub About — English

Satellite land-use classification across 21 classes using TensorFlow/Keras CNNs, EfficientNetB0 transfer learning, autoencoders and PyTorch.

## LinkedIn — English

Built and evaluated deep learning models for the classification of aerial land-use imagery across 21 categories using an augmented UC Merced dataset of 10,500 images. Implemented a dense baseline, a custom CNN, a convolutional autoencoder and transfer learning with EfficientNetB0, followed by fine-tuning. Compared architectures in TensorFlow/Keras and implemented a CNN training loop in PyTorch. The recorded test results reached **86.57% accuracy for the custom CNN** and **98.10% for EfficientNetB0 after fine-tuning**, while the autoencoder achieved **0.001367 test MSE** on normalized images. Applied data pipeline optimization, validation-based training and quantitative model evaluation.

**Technologies:** Python, TensorFlow, Keras, PyTorch, Computer Vision, CNN, EfficientNetB0, Transfer Learning, Fine-Tuning, Autoencoders, Image Classification, Data Preprocessing.

> Results reflect the Kaggle-provided augmented test split; source-image-level isolation was not verified.
